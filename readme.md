This repository contains the existing Astro static website for A-1 Drain Cleaning in Mason City, Iowa.

## Service inventory

The website keeps separate service records for floor drain cleaning, basement drain cleaning, garage drain cleaning, utility sink drain cleaning, kitchen drain cleaning, bathroom drain cleaning, shower drain cleaning, bathtub drain cleaning, roof drain cleaning, storm drain cleaning, yard drain cleaning, main drain cleaning, sewer line cleaning, camera inspections, tree root removal/cutting, hydro jetting, smoke testing, sewer line locating, laundry and washing machine drain cleaning, toilet unclogging, emergency drain cleaning, septic line cleaning, dishwasher drain service, garbage disposal repair and installation, and sump pump repair.

A symptom such as a floor drain backup is not the service name. Kitchen, bathroom, shower, and bathtub drain work remain separate.

## Service-area directory

The nine dedicated Iowa city pages are Mason City, Clear Lake, Charles City, Forest City, Garner, Hampton, Nora Springs, Northwood, and Rockwell. Albert Lea, Minnesota, is also included in the service-area directory.

The community directory includes locations in Cerro Gordo, Floyd, Franklin, Hancock, Mitchell, Winnebago, Worth, and Butler counties. These are directory communities, not separate county landing pages. Do not add Hardin or Chickasaw County.

## Development

Install dependencies and run the existing project scripts:

```sh
npm install
npm test
npm run check
npm run build
```

Keep the existing Astro architecture and GitHub Pages deployment. Make changes on the assigned feature branch, not directly on `main`.
