# A-1 Drain Cleaning website

Astro static site for A-1 Drain Cleaning.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run check
npm run build
```

The production domain is `https://www.a1drain.com`. GitHub Pages serves this custom domain from the repository's `public/CNAME` file.

## Important

The contact form is intentionally not included because no real form endpoint was supplied. The primary contact path is the business phone: 641-530-2728.
