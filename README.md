## About
A-1 Drain Cleaning is a local drain and sewer cleaning business serving Mason City and North Iowa. The site is built with Astro and deployed as a static site through GitHub Pages.

## Development

```bash
npm install
npm run dev
```

Before deployment:

```bash
npm run check
npm run build
```

The production site uses the Astro-generated sitemap and the contact form currently configured in the site components.
