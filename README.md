# A-1 Drain Cleaning

Astro static site for A-1 Drain Cleaning in Mason City, Iowa.

## SEO structure
- Mason City is the primary local entity.
- Service pages target specific drain and sewer problems.
- A limited set of nearby location pages targets real service-area searches without creating dozens of near-duplicate city pages.
- Long-tail queries are addressed in useful, readable copy rather than keyword stuffing.
- Sitemap, robots.txt, LocalBusiness structured data and llms.txt are included.

## Build
npm install
npm run build
